需要注册账号或安装软件吗？

Web 版无需注册账号，也无需安装原生客户端。打开网页、设置显示名称，并和对方加入同一个房间即可开始。若希望自己的 Windows 电脑被远程控制，需要在被控电脑上运行桌面客户端。

手机和电脑可以一起使用吗？

可以。手机浏览器、电脑浏览器和 Windows 桌面端可以加入同一房间，聊天和传输文件。摄像头、屏幕采集、剪贴板与通知等功能取决于设备、浏览器的支持情况和你授予的权限。

文件和聊天记录保存在哪里？

聊天历史、缓存文件与偏好保存在当前浏览器或桌面端的本机存储中，信令服务器不保存聊天记录或文件。浏览器与桌面端的存储相互独立，不会自动同步；清理网站数据也会清除相应的本机记录，请另行保存重要文件。

对方离线后，还能收到消息或下载文件吗？

消息发送和从对方设备下载共享文件，需要双方保持连接。群聊消息只送达当前在线成员，服务器不提供离线消息投递。已完整接收并保存在本机的内容，可以在本机文件库中继续查看。

别人可以直接控制我的电脑吗？

远程控制需要被控端批准请求，或符合你之前保存的允许规则。你可以拒绝请求、管理权限，并随时在本机撤销控制。Windows 显示器共享支持控制，窗口共享仅支持观看；剪贴板同步和远程文件拖放默认关闭。

可以部署自己的 Weblink 吗？

可以。Weblink 基于 MIT 协议开源，可托管 Web 静态构建产物并连接自己的信令服务。仓库提供 Bun 和 Cloudflare Workers 两种信令实现，也可按网络条件配置 STUN / TURN。具体配置请查看部署文档。
