# 快速开始

Weblink 连接设备，让你聊天、传文件、通话、共享屏幕和远程控制电脑。先选择这次想完成的任务：

- **传文件或开始聊天**：[连接两台设备](#connect-two-devices)，两端都可以使用浏览器。
- **从手机或另一台电脑操作 Windows 电脑**：[开始远程控制](#first-remote-session)，只需在被控电脑安装桌面端。

## 每台设备该打开什么？ {#choose-your-client}

| 你的任务          | 第一台设备                           | 另一台设备                                 |
| ----------------- | ------------------------------------ | ------------------------------------------ |
| 聊天、传文件      | 浏览器或桌面端                       | 浏览器或桌面端                             |
| 语音或视频通话    | 已授权麦克风、摄像头的浏览器或桌面端 | 已授权麦克风、摄像头的浏览器或桌面端       |
| 控制 Windows 电脑 | **主机**：Windows 桌面端             | **控制端**：手机浏览器、电脑浏览器或桌面端 |

**主机**是被操作的电脑，**控制端**负责发送鼠标、触摸和键盘输入。浏览器可以控制受支持的主机，但不能接收远程输入来操作自身所在的电脑。准备主机前，先确认[桌面端安装与系统要求](guide/desktop.md)。浏览器采集功能需要受支持的浏览器、HTTPS 或 localhost，以及系统权限。

## 连接两台设备，传送第一个文件 {#connect-two-devices}

1. **在第一台设备上**，打开 [webl.ink](https://webl.ink) 或启动桌面端。填写显示名称和房间 ID，可按需设置房间密码，然后加入房间。
2. **在另一台设备上**，打开 Weblink，使用相同的 **WebSocket URL、房间 ID 和密码**加入。两端都使用默认服务时，无需修改连接设置；也可以使用房间邀请链接或二维码。
3. **两端都确认**对方已出现在房间中，并等待连接与设备配对完成。先发送一条简短消息，确认另一台设备能收到。
4. **发送端**在聊天中添加一个小文件并发送。**接收端**若未自动下载，点击文件消息的下载操作，等待传输完成。
5. **接收端**打开或预览完成的文件。需要在 Weblink 的浏览器存储之外保留副本时，在文件操作中选择**保存到设备**。

**成功的标志**：另一台设备能收到消息并打开传送的文件。仅在房间中看到成员，还不能证明 WebRTC 连接可用；未能完成上述验证时，按[连接排查](guide/faq.md#connection)检查。

大文件与共享列表的操作见[文件传输指南](guide/files.md)；直接写入本地目录的方式见[文件存储](guide/storage.md)。

## 开始第一次远程控制 {#first-remote-session}

1. **主机**[安装并打开 Windows 桌面端](guide/desktop.md)，保持运行并加入房间。
2. **控制端**使用浏览器或桌面端打开 Weblink，[加入同一房间](#connect-two-devices)。手机无需安装桌面端。
3. **控制端**在会议区域选中主机的卡片，展开画面操作，点击**请求控制**。主画面通过悬浮按钮展开操作。
4. **主机**核对**允许远程控制？**中的设备名称，选择**允许本次会话**。如果请求会启动屏幕共享，批准后会按提示将**屏幕 1 及其音频共享给房间内所有成员**。
5. **控制端**打开共享的显示器画面，确认状态为**控制中**，再尝试移动指针。电脑上打字前先**开启键盘控制**；手机上在画面操作中选择**打开键盘**。
6. 使用结束后点击**结束控制**；主机若仍在共享画面，再结束屏幕共享。

**成功的标志**：控制端看到了主机桌面，输入也能改变主机的指针或应用状态。能看画面不等于已经获准输入。[远程桌面指南](guide/remote-control.md#connect)会继续说明如何选择显示器、使用触摸手势、释放输入和撤销权限。

## 连接与数据保存 {#how-connections-work}

设备需要使用相同的信令服务才能发现彼此。消息、文件和媒体通过 WebRTC 传输，部分网络需要 TURN 中继。默认 WebSocket 服务较慢或无法访问时，先看[连接常见问题](guide/faq.md#signaling-mainland)；也可以[只部署信令服务](deployment/overview.md)，在现有客户端修改 WebSocket URL 使用。

聊天记录、设备身份和权限保存在当前本地配置中，不会通过账号同步；房间不提供离线消息，也不会把加入前的历史发送给新成员。加入房间不会自动授予远程控制或自动化权限。
