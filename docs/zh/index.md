# 快速开始

Weblink 通过 WebRTC 连接设备，提供聊天、文件传输、音视频和远程桌面。可以直接使用浏览器，也可以安装 Windows 桌面端。

## 连接两台设备 {#connect-two-devices}

1. 在第一台设备打开 [webl.ink](https://webl.ink)，或启动桌面端。
2. 设置显示名称和房间 ID，需要限制进入时填写房间密码。
3. 在另一台设备使用相同的**信令服务、房间 ID 和密码**加入，也可以使用邀请链接或二维码。
4. 等待设备连接与配对完成，发送一条消息，再尝试传输一个文件。

出现成员但不能发送内容时，先看[连接排查](guide/faq.md#connection)。加入房间不会自动开放远程控制或系统自动化权限。

## 选择客户端 {#choose-your-client}

| 你想做什么                           | 使用方式                                     |
| ------------------------------------ | -------------------------------------------- |
| 聊天、传文件、摄像头或麦克风通话     | 浏览器或桌面端                               |
| 从手机控制电脑                       | 手机浏览器作为控制端，Windows 桌面端作为主机 |
| 原生屏幕共享、接收远程输入           | Windows 桌面端                               |
| 连接 HTTP MCP 客户端、执行系统自动化 | Windows 桌面端                               |

安装步骤与系统要求见[桌面端使用](guide/desktop.md)。浏览器媒体功能通常需要 HTTPS 或 localhost，以及对应系统权限。

## 连接与数据保存 {#how-connections-work}

信令服务帮助设备发现彼此；消息、文件和媒体通过 WebRTC 传输，网络不允许直连时可能需要 TURN 中继。想理解客户端、信令与中继的分工，可阅读[架构概览](architecture/overview.md)；想使用自己的服务，可从[自部署导读](deployment/overview.md)选择部署范围。

聊天记录、设备身份和权限属于当前本地配置，不会通过账号在不同设备间自动同步。房间面向在线成员，不提供离线消息或新成员历史同步。
