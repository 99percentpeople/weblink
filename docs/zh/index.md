# 快速开始

先选一件想完成的事：[传送文件](#connect-two-devices)，或[远程控制电脑](#first-remote-session)。

## 准备设备 {#choose-your-client}

聊天、传文件和通话，使用浏览器打开 [Weblink](https://webl.ink) 或启动桌面端即可。需要控制电脑时，在被控电脑（**主机**）安装 [Windows 桌面端](guide/desktop.md)；手机、电脑浏览器或另一台桌面端都可以作为**控制端**。

## 连接并传送文件 {#connect-two-devices}

1. **第一台设备**打开 Weblink，点击**加入房间**，填写名称与房间 ID，再点击**连接**。
2. **另一台设备**加入相同房间；设有密码时填写相同密码。也可以使用第一台设备的**用户菜单 → 分享链接**邀请加入。
3. **发送端**打开聊天，发送一个小文件；**接收端**点击附件上的传输操作，等待完成后打开文件。

传输完成前保持发送端在线。看到附件卡片不代表文件已下载，完整操作见[文件传输](guide/files.md)。

## 远程控制 Windows 电脑 {#first-remote-session}

1. **主机**打开 Windows 桌面端并加入房间；**控制端**打开 Weblink，加入同一房间。
2. **控制端**选中主机卡片，展开画面操作，点击**请求控制**。
3. **主机**核对申请设备，选择**允许本次会话**。
4. **控制端**打开共享画面并尝试移动指针。需要打字时，电脑上**开启键盘控制**，手机上选择**打开键盘**。

从成员卡片发起的请求可能将**屏幕 1 及其音频共享给房间内所有成员**。批准后，对方可以操作主机鼠标和键盘。

结束时点击**结束控制**；主机若仍在共享屏幕，也要停止共享。选择显示器和释放输入的操作见[远程桌面](guide/remote-control.md)。

::: details 使用自建服务器，或想了解数据保存在哪里？

### 连接与本地数据 {#how-connections-work}

两端需要使用同一 WebSocket 信令服务器。普通使用保留默认值即可；接入自建服务时，在每台设备的[连接设置](guide/connection.md#signaling)中填写相同地址。

消息、文件和媒体通过 WebRTC 传输，必要时使用 TURN 中继。可以[只部署信令服务](deployment/overview.md)，继续使用现有客户端。

聊天历史、身份和权限保存在当前本地配置，不会通过账号同步；房间不提供离线消息，也不向新成员发送之前的历史。
:::

## 接下来想做什么？ {#start-collaborating}

- **想邀请别人或使用私聊**：阅读[房间与聊天](guide/rooms.md)。
- **想通话、共享屏幕或保存录像**：选择[屏幕共享与通话](guide/media.md)或[录制与保存](guide/recording.md)。
- **想指定保存目录或管理设备访问**：前往[文件存储](guide/storage.md)或[设备权限](guide/device-trust.md)。
- **连接或播放遇到问题**：在[常见问题](guide/faq.md)中查找对应现象。
