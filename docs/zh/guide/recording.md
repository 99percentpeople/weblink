# 录制与保存

在发起录像的设备上录制**一个视频来源及其关联音频**，不会自动合成所有参与者，也不会在其他设备各保存一份。

### 录制前 {#prepare}

打开本地或接收的视频来源，确认画面和声音。检查**设置 → 传输 → 文件存储**；首次录制时，**设置 → 音视频 → 录像**保持**自动**即可。

## 开始录像 {#start}

1. 选中来源，展开画面操作；主画面使用悬浮按钮。
2. 点击**开始录像**，等待准备完成。
3. 在顶部录像状态中核对来源名称，确认计时增加。

同一时间只能录制一个来源；切换主画面不会改变正在录制的来源。

## 暂停或完成 {#stop-and-save}

使用**暂停录像**与**继续录像**可继续写入同一文件。结束时点击**停止并保存**，等待**录像已保存**。

**保存完成前保持应用或页面打开。**暂停不代表文件已完成；刷新、关闭或主动离开房间前，先停止并保存。

## 找到并导出文件 {#find-file}

从**录像已保存**通知打开，或在**用户菜单 → 文件缓存**按来源名称与时间戳查找。

- 浏览器存储使用**保存到设备**导出副本。
- 本地目录使用**另存为**复制到其他位置；Windows 可用**打开位置**定位原文件。

用计划使用的播放器打开完成的文件，确认结果。

::: details 来源结束，或中途修改了保存位置

来源结束、被替换或离开会话，会结束并保存录像；关闭菜单或文件面板不会停止它。

录像沿用开始时的存储位置，修改默认位置不会移动它。查找时在文件库选回原位置，见[文件存储](storage.md#change-directory)。
:::

::: details 选择 MP4、MKV 与确认播放兼容性

### 录像格式 {#formats}

在**设置 → 音视频 → 录像**选择**自动**、**MP4**或 **MKV**，对下一次录像生效。

自动选择保留编码的容器。复用原编码时，H.264/H.265 通常使用 MP4，其他受支持的视频编码使用 MKV；G.722、PCMU 或 PCMA 音频会选择 MKV。实际链路取决于来源和运行环境，以文件扩展名为准。

**MP4 是容器，不保证视频是 H.264。**其中也可以是 H.265，修改扩展名不会转换编码；手动选择容器可能需要重新编码音频。

需要更广的兼容性时，使用可用的 H.264 来源，先用短录像验证目标播放器。实时观看与文件播放可能使用不同解码器，底层过程见[媒体传输与录制](../architecture/media.md)。
:::
