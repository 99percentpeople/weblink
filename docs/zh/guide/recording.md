# 录制与保存

录制一个本地或接收的视频来源及其关联音频。文件保存在发起录像的设备上，不会自动合成所有参与者的会议录像，也不会自动在其他设备各保存一份。

## 准备来源与保存位置 {#prepare}

1. 开启[摄像头或屏幕共享](media.md)，或打开另一台设备发送的视频来源。确认能看到需要的画面，来源中也包含需要录下的音频。
2. 在准备录制的设备上打开**设置 → 传输 → 文件存储**，确认目标位置；提示目录授权时允许访问。
3. 在**设置 → 音视频 → 录像**中，第一次使用保留**自动**，也可以按需[选择格式](#formats)。
4. 先录一小段，用计划使用的播放器检查保存结果。

| 存储方式                | 录像保存到哪里                                                                    |
| ----------------------- | --------------------------------------------------------------------------------- |
| 浏览器存储（IndexedDB） | 当前浏览器配置下的 Weblink 存储；需要在站点之外保留时，使用**保存到设备**导出副本 |
| 本地目录                | 已选择的目录；桌面端默认使用本地应用数据目录，也可另选位置                        |

录像沿用开始时的存储位置，中途切换默认目录不会移动正在录制的文件。仍需要目录访问授权和足够空间；设置方式见[文件存储](storage.md#choose-storage)。

## 开始并确认正在录像 {#start}

1. 在会议区域选中需要录制的视频来源。
2. 展开它的画面操作：主画面使用悬浮按钮，小卡片使用对应卡片的操作按钮。
3. 点击**开始录像**，等待准备完成。
4. 确认会话顶部显示**正在录像**，且计时持续增加；显示空间足够时还会展示已写入大小。

同一时间只能有一个录像任务；已有录像时，不能为其他来源再启动第二个任务。切换主画面不会切换正在录制的来源，应通过录像状态中的来源名称确认。

## 暂停、继续与完成 {#stop-and-save}

- 在来源操作或顶部录像状态中点击**暂停录像**，暂时停止采集，但保留当前录像任务。
- 点击**继续录像**，继续写入同一个文件。
- 点击**停止并保存**完成录像，等待**正在保存录像**结束，并出现**录像已保存**通知。

**成功的标志**：完成的录像已成为可打开的文件。计时正在增加或处于暂停状态，都不代表文件已经完成保存。

保存完成前保持应用或页面打开。关闭来源菜单或文件面板不会停止录像；来源结束、被替换或离开会话会结束并保存。主动结束时，应先点击**停止并保存**，再离开、刷新页面或关闭应用。

## 找到、预览与导出文件 {#find-file}

1. 使用**录像已保存**通知中的打开操作，或进入录像保存位置对应的文件库。
2. 按来源名称和时间戳找到文件，确认保存完成后再打开。
3. 在预览或支持该文件音视频编码的播放器中检查结果。
4. 需要在其他位置保留副本时，按当前存储方式选择操作：

| 文件位置     | 操作                                             |
| ------------ | ------------------------------------------------ |
| 浏览器存储   | **保存到设备**：通过浏览器导出副本               |
| 本地目录     | **另存为**：在其他位置创建副本                   |
| Windows 目录 | **打开文件位置**：在系统文件管理器中定位已有文件 |

开始录像后如果更改过默认存储位置，将文件库切回原位置查看；文件不会跟随新默认目录移动。需要发给别人时，使用[文件传输或共享](files.md)。

## 选择 MP4、MKV 或自动 {#formats}

**设置 → 音视频 → 录像**中的选择对下一次录像生效。

| 选项 | 适用情况                                              |
| ---- | ----------------------------------------------------- |
| 自动 | 首次使用从这里开始，让 Weblink 选择能保留原编码的容器 |
| MP4  | 目标播放器支持 MP4，并支持来源的音视频编码            |
| MKV  | 播放器支持 Matroska 以及需要保留的编码                |

复用原始编码时，自动模式通常为 H.264/H.265 选择 MP4，为其他受支持的视频编码选择 MKV；音频为 G.722、PCMU 或 PCMA 时，自动模式选择 MKV。可用录制链路取决于来源与运行环境，以完成文件的扩展名为准。

**容器不等于编码。**MP4 中也可以是 H.265；选择 MP4 不保证视频转为 H.264，修改扩展名也不会转换文件。手动指定容器时，可能需要重新编码音频。

需要更广的播放兼容性时，使用可用的 H.264 来源，并先用一段短录像验证目标播放器。实时观看与文件播放可能使用不同的解码链路，能观看不能直接证明该播放器也能打开录像。
