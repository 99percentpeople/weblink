# 音视频与录制

加入房间并连接设备后，可以开启麦克风、摄像头或共享屏幕。浏览器使用系统提供的采集选择器；Windows 桌面端还提供原生显示器和窗口共享。

## 开启语音和摄像头 {#camera-and-microphone}

1. 在会话的音视频操作中开启麦克风或摄像头。
2. 按提示授予浏览器和操作系统权限。
3. 在**设置 → 音视频**选择设备并调整偏好。
4. 确认本地预览与静音状态，再请对方确认声音和画面。

浏览器通常需要 HTTPS 或 localhost。局域网 HTTP 页面能打开，不代表摄像头、麦克风和屏幕采集都可用。

## 共享显示器或窗口 {#screen-sharing}

从屏幕共享操作选择需要分享的来源，再确认开始。系统音频是否可选取决于平台、浏览器和来源类型。

Windows 桌面端的选择器区分显示器和窗口。窗口共享用于观看；要让另一台设备控制电脑，应选择显示器并按[远程桌面](remote-control.md)授权。

停止共享请使用共享状态或来源上的停止操作。隐藏主窗口、关闭来源菜单不会自动结束已有共享。

## 调整画质与声音 {#quality}

在**设置 → 音视频**调整分辨率、帧率和码率。较高的设置需要更多网络带宽和设备性能，设置值是目标或上限，不保证实际达到。

自动编码会从发送端能编码、目标设备能解码的格式中选择。原生屏幕和摄像头发布按接收方分别选择；手动指定仍需要兼容的接收端。

桌面端可用的采集方式和编码器由系统与硬件决定。分辨率、帧率和码率可以影响活动流；更改编码器、编解码器或采集后端后，需要重新开始共享才能使用新选择。不确定时使用自动选项。

声音需要同时确认来源的静音状态和观看端播放音量。共享系统声音时，选择支持音频的采集来源，并在采集选择器提供该选项时勾选音频。

需要主动调整画质时，可以按以下顺序进行：

1. 先使用自动编码与编码器选择，确认目标设备能够接收画面。
2. 阅读文字和桌面细节时，优先保证可辨识的分辨率；观看运动画面时，在码率与处理能力允许的范围内调整帧率。
3. 每次只修改一个参数。提高码率上限不会增加网络容量；现有预算无法支撑时，降低帧率或分辨率。
4. 桌面端需要明确控制时，再选择探测到的编码器与格式组合。硬件编码、原生解码和 GPU 显示是不同环节。
5. 来源支持时，观看端可以请求较低的接收分辨率、FPS 或码率，请求仍受发送方上限限制。

这些取舍以及浏览器与原生链路的区别，见[编码、解码与 GPU 显示](../architecture/codecs.md)，其中也说明了硬件加速和 CPU 回退的条件。具体浏览器故障仍集中在常见问题中。

## 录制一个视频来源 {#recording}

1. 在准备录制的视频来源菜单中开始录制。
2. 在会话顶部查看录制状态、时间及已写入大小。
3. 需要暂停时使用暂停，继续后仍写入同一个文件。
4. 结束时点击停止，等待保存完成，再到文件库中预览或保存副本。

一次只能录制一个本地或接收的视频来源，以及该来源关联的音频，不会自动录下整个会议的所有参与者。

在**设置 → 音视频 → 录制**选择自动、MKV 或 MP4。复用原始媒体编码时，自动模式通常将 H.264/H.265 保存为 MP4，其他受支持的视频编码保存为 MKV；包含 G.722、PCMU 或 PCMA 音频时使用 MKV。实际可用格式取决于来源与运行环境，以完成文件的扩展名为准；外部播放器也需要支持文件内的编码。

录制使用开始时的[文件存储位置](storage.md)，中途切换默认目录不会移动录制。关闭菜单或文件面板不会停止它；来源结束、被替换或离开会话会结束并保存录制。
