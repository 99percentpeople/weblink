# 屏幕共享与通话

通过会议控制栏与房间成员通话、开启摄像头或展示屏幕。需要把视频来源保存成文件时，使用独立的[录制与保存指南](recording.md)。

## 第一次通话或共享前 {#before-you-start}

1. [连接设备](../index.md#connect-two-devices)，确认聊天消息能到达对方。
2. 打开会话底部的会议控制栏；如果控制栏已收起，先展开。
3. 准备需要使用的麦克风、摄像头或屏幕。浏览器通常要求 HTTPS 或 localhost，以及浏览器和系统权限；局域网 HTTP 页面能打开，不代表可以采集。
4. 两台设备处于同一个物理房间时，使用耳机或关闭一端播放声音，避免回声。

麦克风声音与采集到的系统声音是不同来源。关闭麦克风，不一定会关闭随屏幕共享发送的声音。

## 开始语音或视频通话 {#camera-and-microphone}

1. **说话的一端**在底部控制栏点击**开启麦克风**，按提示允许使用麦克风。
2. 还需要发送画面时，点击**开启摄像头**并授予摄像头权限。
3. 在对应控件旁的**音频设备**或**摄像头设备**中选择设备；更多偏好位于**设置 → 音视频**。
4. 检查本地摄像头预览。**另一端**确认能听到说话声、看到摄像头画面，并检查播放音量以及该成员是否被静音。
5. 需要双向通话时，另一端也按上述步骤开启麦克风或摄像头。

**成功的标志**：对方收到了你的声音或摄像头画面。本地预览只能证明本机采集正常。只需要语音时，可以保持摄像头关闭。

点击**关闭麦克风**或**关闭摄像头**可停止对应来源，同时留在房间中。

## 共享屏幕，并按需包含系统声音 {#screen-sharing}

1. **共享端**在底部控制栏点击**共享屏幕**。
2. 在采集选择器中选择客户端提供的屏幕、窗口或浏览器标签页，核对来源后再确认开始。
3. 需要发送系统或标签页声音时，在选择器提供该选项的情况下开启音频。音频是否可用取决于操作系统、浏览器与来源类型。
4. **接收端**在会议区域选中共享来源，将其打开为主画面。请对方分别确认画面和你打算发送的声音。
5. 已经共享时，如果客户端提供**添加共享画面**操作，可以用它增加另一个来源。

Windows 桌面端的选择器区分显示器和窗口。展示单个应用可以选择窗口；需要让对方操作电脑时，应共享显示器并完成[远程桌面授权](remote-control.md#connect)，仅能观看不代表已经允许输入。

**成功的标志**：在所选来源中移动内容，接收端能看到变化；包含声音时，播放一小段内容，让对方确认能听到。打开菜单或看到本地预览不能代替这个验证。

手机可以接收共享画面，也可以作为远程控制端；手机自身能否采集屏幕取决于浏览器和平台，不能假定它具有桌面端的采集选择器。

## 调整画质与声音 {#quality}

打开**设置 → 音视频**。第一次连接保留自动编解码器与编码器选择，确认可用后每次只改一个设置。

| 你的重点           | 调整方式                                                        |
| ------------------ | --------------------------------------------------------------- |
| 阅读文字和桌面细节 | 先保证可辨识的分辨率，再平衡帧率与码率                          |
| 流畅展示运动画面   | 在带宽和处理能力允许的范围内提高帧率                            |
| 减少带宽或处理负担 | 降低分辨率或帧率；提高码率上限不会增加网络容量                  |
| 指定桌面编码器     | 选择已探测到、且接收端支持的编码器与格式组合，然后重新共享      |
| 听到预期的声音     | 分别检查麦克风静音、采集音频选项、接收端成员/来源静音与播放音量 |

分辨率、帧率和码率是目标或上限，不保证实际达到；修改它们可以影响活动流。更改编码器、编解码器或采集后端后，需要重新开始共享才能使用新选择。

自动编码会从发送端能编码、接收端能解码的格式中选择；原生屏幕和摄像头发布按接收方分别选择。手动指定仍需要兼容的接收端。硬件编码、原生解码和 GPU 显示是不同环节，选择编码器不能单独决定整条链路。

来源支持时，观看端可以在发送方上限内请求较低的接收分辨率、FPS 或码率。浏览器与原生端的详细行为见[编码、解码与 GPU 显示](../architecture/codecs.md)。

## 停止共享或结束通话 {#stop-sharing}

- **停止麦克风或摄像头**：使用底部控制栏中对应的控件。
- **停止某个共享画面**：使用该本地来源的关闭操作。会议控制栏中的**结束共享**用于结束屏幕共享。
- **离开会话**：退出房间，结束当前实时连接。

确认接收端已经看不到该来源。关闭来源菜单、隐藏主窗口或切换面板不会停止正在进行的共享。麦克风、摄像头和屏幕共享分别控制，结束前应检查自己开启过的每个来源。

## 录下正在观看的来源 {#recording}

在视频来源的画面操作中选择**开始录像**。一次只能录制一个本地或接收的视频来源，以及该来源关联的音频，不会自动录下所有参与者。

准备工作、暂停与继续、**停止并保存**以及完成文件的位置，见[录制与保存](recording.md)。其中的[格式说明](recording.md#formats)解释 MP4、MKV 与播放兼容性。

## 接下来想了解什么？ {#troubleshooting}

- **想操作正在观看的那台电脑**：继续设置[远程桌面](remote-control.md)。
- **想理解硬件加速与 CPU 回退**：对比[视频](../architecture/codecs.md#comparison)和[音频](../architecture/audio.md#comparison)链路。
- **浏览器无法采集、没有声音或画面黑屏**：分别查看[采集](faq.md#capture)、[音频](faq.md#no-audio)或[视频](faq.md#video)常见问题。
