# 屏幕共享与通话

### 开始前 {#before-you-start}

[加入同一房间](rooms.md#join)后，使用底部会议控制栏操作。浏览器需要采集权限，通常还需要 HTTPS 或 localhost。附近多台设备可能产生回声时使用耳机。

## 语音或视频通话 {#camera-and-microphone}

1. 点击**开启麦克风**，需要视频时再**开启摄像头**，并按提示允许访问。
2. 请对方确认能听到、看到你；双向通话时，对方也开启自己的麦克风或摄像头。

在控件旁的**音频设备**或**摄像头设备**中选择设备；点击**关闭麦克风**或**关闭摄像头**停止对应来源。

## 共享屏幕与声音 {#screen-sharing}

1. 点击**共享屏幕**，选择客户端提供的屏幕、窗口或标签页并确认。
2. 需要系统或标签页声音时，在选择器提供该选项的情况下开启音频。
3. 请接收端选中共享来源，确认画面与声音。

**麦克风和共享的系统声音分别控制。**关闭麦克风后，共享声音可能仍在发送。系统音频和手机屏幕采集是否可用，取决于平台、浏览器和所选来源。

Windows 桌面端可以共享显示器或窗口；需要让对方操作电脑时，共享显示器并完成[远程控制授权](remote-control.md#connect)。

::: details 添加其他画面或调整画质

共享期间，客户端提供**添加共享画面**时，可以增加另一个来源。

### 画质与声音设置 {#quality}

打开**设置 → 音视频**，先使用自动编解码器与编码器选择，每次只调整一个选项。

- 阅读文字时，优先保证可辨识的分辨率。
- 展示运动时，在带宽和设备性能允许的范围内调整帧率。
- 减少负担时，降低分辨率或帧率；提高码率上限不会增加网络容量。
- 修改编解码器、编码器或采集后端，需要重新共享；分辨率、帧率与码率可影响活动流，但只是目标或上限。

自动选择会考虑两端支持情况，原生发布按接收方选择。观看端可在发送方上限内请求较低画质。硬件编码、解码和 GPU 显示是不同环节，详细对比见[视频](../architecture/codecs.md#comparison)和[音频](../architecture/audio.md#comparison)链路。
:::

## 停止共享或离开 {#stop-sharing}

使用麦克风和摄像头控件停止对应来源。单个共享画面可通过来源操作关闭，底部**结束共享**可结束屏幕共享；退出房间则结束实时连接。

**关闭菜单、隐藏窗口或切换面板不会停止共享。**结束时检查开启过的来源，麦克风、摄像头与屏幕共享分别控制。

### 保存录像 {#recording}

在视频来源的画面操作中点击**开始录像**，再按[录制与保存](recording.md)完成并找到文件。

## 接下来想了解什么？ {#troubleshooting}

- **想操作正在观看的那台电脑**：设置[远程桌面](remote-control.md)。
- **无法采集、没有声音或画面黑屏**：查看[采集](faq.md#capture)、[音频](faq.md#no-audio)或[视频](faq.md#video)常见问题。
