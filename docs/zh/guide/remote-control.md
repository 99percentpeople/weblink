# 远程桌面

被控电脑需要运行 Windows 桌面端。控制端可以是手机浏览器、电脑浏览器或另一台桌面客户端。

## 建立控制连接 {#connect}

1. 在被控电脑[安装并打开桌面端](desktop.md)。
2. 两端使用相同信令服务、房间 ID 和密码加入房间，等待[设备配对](device-trust.md)完成。
3. 从成员操作或共享显示器的操作中请求控制。
4. 主机在通知中批准请求，或按已保存的允许规则授权。
5. 控制端打开远程画面，开始使用鼠标、触摸或键盘。

批准请求可以启动显示器共享。**窗口共享仅供查看**，要接收远程输入需要共享可控制的显示器。

## 权限与结束控制 {#permissions}

在成员详情或**设置 → 客户端与房间**打开对应设备的权限，选择询问、始终允许或拒绝。加入房间、知道显示名称或持有邀请链接不会自动授予控制权。

控制端可以在画面操作中结束控制。主机可以从共享状态撤销控制，或停止对应显示器共享；离开房间也会结束当前控制连接。

| 操作           | 默认快捷键           | 作用                                               |
| -------------- | -------------------- | -------------------------------------------------- |
| 控制端释放输入 | `Ctrl+Alt+Shift+Q`   | 释放捕获的指针并关闭键盘转发，保留已批准的控制连接 |
| 主机紧急停止   | `Ctrl+Alt+Shift+F10` | 撤销当前远程输入，也停止相关自动化输入和命令       |

快捷键可在远程控制设置中修改，以当前设置显示的组合为准。释放输入后，需要重新启用键盘转发才能继续发送键盘操作。

## 鼠标、键盘与手机触摸 {#input}

在**设置 → 远程控制**调整输入偏好：

- 鼠标可选择本地指针或捕获模式；捕获后使用释放快捷键返回本机操作。
- 键盘转发与指针捕获分别控制。失去窗口焦点会释放当前输入，返回页面后按界面提示恢复。
- 手机可使用触控板模式，单指移动、轻点点击，并按设置启用双指右键、滚动和缩放。
- 触摸速度、滚动方向、长按动作和采样率影响当前控制端的操作体验，不改变主机授权。

操作系统保留的快捷键和受保护界面不保证能远程操作。Windows 较高权限的窗口也可能拒绝来自普通权限应用的输入。

## 远程剪贴板与文件拖放 {#clipboard-and-files}

需要在两端复制内容时，在**设置 → 传输**开启远程剪贴板同步。支持的文本、富文本、图片和文件类型取决于两端能力；剪贴板文件可以按设置写入本机剪贴板或保存到文件库，也可以关闭文件接收。

同一设置区域还可开启远程文件拖放。将本地文件拖到远程画面上，可复制到兼容的 Windows 应用；文件夹会打包为 ZIP。目前不支持把文件从远程画面直接拖出到控制端的操作系统。

这两项功能默认关闭，并要求有效的远程控制授权。文件操作默认上限为 64 MiB，可在传输设置中调整为 1–512 MiB。

## 调整观看体验 {#viewing}

使用全屏或画中画查看远程画面；桌面端还可使用原生置顶窗口。根据网络调整分辨率、帧率和码率，必要时降低画质。

在流统计中查看连接状态和当前路径，也可以运行[连接测速](connection.md#speed-test)。测速反映当前设备之间的吞吐，不代表公网带宽。
