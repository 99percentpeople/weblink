# 远程桌面

**主机**是被控制的电脑，**控制端**是你用来操作它的设备。

### 开始前 {#before-you-start}

主机运行 [Windows 桌面端](desktop.md)，控制端使用手机浏览器、电脑浏览器或桌面端，两端[加入同一房间](rooms.md#join)。

## 开始控制 {#connect}

### 主机：共享显示器 {#share-monitor}

在底部控制栏点击**共享屏幕**，选择显示器并确认；需要声音且选择器提供音频选项时一并开启。**窗口共享仅供查看**，远程输入需要共享显示器。

### 控制端：申请操作 {#request-control}

选中共享显示器，通过悬浮按钮展开画面操作，点击**请求控制**。等待期间可点击**取消请求**撤回。

### 主机：批准设备 {#approve-and-check}

核对“**允许远程控制？**”中的设备，选择**允许本次会话**。控制端出现**控制中**后，尝试移动指针。

**授权允许操作主机鼠标和键盘，不局限于某个应用或显示器**。点击系统通知只是打开请求，选择批准操作后才会授权。

::: details 主机还没有共享屏幕，如何发起控制？

从主机的成员卡片申请控制。批准后可能将**屏幕 1 及其音频共享给房间内所有成员**。需要使用其他显示器时，让主机按上面的步骤先共享。
:::

## 无人值守访问 {#unattended}

为自己的 Windows 主机保存控制端授权后，后续请求可以自动批准，无需每次到主机前确认。

1. 两端先加入同一房间，完成一次连接与[设备配对](device-trust.md#pairing)。
2. 在**主机**的**设置 → 客户端与房间**选择控制端，把**远程控制**设为**永久允许**，并保持**接收内容**和**共享屏幕**为允许。也可在首次请求的**更多批准选项**中选择**批准并加入白名单**。
3. 让主机保持在线，控制端重新连接后，从主机成员卡片点击**请求控制**，确认无需主机再次批准即可操作。

**主机需要已登录 Windows，保持开机、联网且未休眠**。授权按设备身份保存；换浏览器配置或清除数据后，需要重新配对和授权。

无需事先手动共享屏幕。主机尚未共享显示器时，从成员卡片请求控制会自动将**屏幕 1 及其音频共享给房间内所有成员**。

::: details 登录后自动上线与托盘驻留

在主机的**设置 → 应用**中配置：

- 开启**开机自动启动**与**自动加入**，让应用在登录 Windows 后启动，并加入已经配置好的房间。
- 将**开机启动后的行为**设为**后台驻留托盘**，将**关闭窗口时**设为**隐藏到系统托盘**，保持后台连接。还可开启**批准远程控制后隐藏窗口**。

先退出并重新打开应用，检查自动入房与自动批准，再验证一次 Windows 登录后的启动。手动打开应用仍会显示主窗口；托盘不可用时，自动隐藏不会生效。

自动启动发生在用户登录后，当前不提供登录前运行的系统服务。重启后尚未登录 Windows、电脑休眠或从托盘退出应用时，无法靠这些设置保持在线。

只想让已授权设备看到远控入口时，可关闭**设置 → 远程控制 → 开放远程控制能力**；已加入白名单的设备仍可请求控制。取消长期访问时，将该设备的远程控制改为询问或拒绝。
:::

## 使用鼠标、键盘或手机 {#input}

- **电脑键盘**：打字前先**开启键盘控制**。
- **手机**：触控板模式下单指移动、轻点点击；在画面操作中选择**打开键盘**输入文字。
- **返回本机操作**：默认按 **Ctrl+Alt+Shift+Q**，释放指针捕获并关闭键盘转发，保留已批准的连接。

::: details 指针捕获、触摸手势与输入限制

在**设置 → 远程控制**调整本地指针/捕获模式、触摸速度、滚动方向、长按动作与手势。键盘转发和指针捕获分别控制。

失去焦点会释放当前输入，需要时重新恢复捕获或键盘转发；使用释放快捷键后，要重新开启键盘控制才能发送按键。

操作系统保留快捷键、受保护界面和较高权限的 Windows 应用可能不接受远程输入。
:::

## 结束控制与共享 {#permissions}

- 在控制端或主机控制状态中点击**结束控制**。
- 同时停止展示桌面时，在主机点击**关闭画面**或结束屏幕共享。
- 主机紧急停止默认按 **Ctrl+Alt+Shift+F10**，也会停止相关自动化输入和命令。

**结束控制后，屏幕可能仍在共享**。使用完毕检查两项状态。快捷键可在**设置 → 远程控制**修改，以当前界面显示为准。

已保存的允许规则不会因断线清除，后续请求可能自动获批。需要修改时，在**设置 → 客户端与房间**选择设备，将远程控制改为询问或拒绝，详见[设备权限](device-trust.md#permissions)。

::: details 复制内容或向远端桌面拖放文件

### 剪贴板与文件拖放 {#clipboard-and-files}

两项功能默认关闭，且需要有效的控制授权，可在**设置 → 传输**开启。

剪贴板类型取决于两端能力，剪贴板文件可进入本机剪贴板或文件库。文件拖放将本地文件复制到兼容的 Windows 应用，文件夹打包为 ZIP；不支持从远程画面拖出文件到控制端操作系统。

文件默认上限为 64 MiB，可调整为 1–512 MiB。普通[文件传输](files.md)无需远程控制。
:::

::: details 全屏、画中画与画质

### 观看选项 {#viewing}

画面操作中可以选择全屏或画中画；桌面端也支持原生置顶窗口。

先使用自动编码，阅读文字优先保证分辨率，连接吃力时降低分辨率或帧率。哪些设置需要重新共享，见[共享画质](media.md#quality)，也可以[测试连接](connection.md#speed-test)。
:::

## 接下来想了解什么？ {#unavailable}

- **想把远程屏幕保存成文件**：使用[录制与保存](recording.md)。
- **无人值守主机离线，或仍要求批准**：检查[自动上线](faq.md#unattended-offline)与[设备授权](faq.md#unattended-approval)。
- **连接失败或画面黑屏**：按[连接](faq.md#peer-connection)或[视频](faq.md#video)检查排查。
