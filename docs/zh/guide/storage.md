# 文件存储与管理

从**用户菜单 → 文件缓存**管理文件。虽然入口叫“文件缓存”，本地目录中的内容仍是真实文件；聊天历史、身份和权限另行保存。

## 选择新文件的保存位置 {#choose-storage}

1. 打开**用户菜单 → 设置 → 传输 → 文件存储**。
2. 选择**浏览器存储**，或使用**本地目录 → 选择目录**并允许访问。
3. 核对显示的位置，接收一个小文件，再到**文件缓存**中查找。

浏览器默认使用浏览器存储，桌面端默认使用本地应用数据目录。浏览器选择目录需要支持目录访问、HTTPS 等安全上下文和你的授权。

**更换位置只影响新文件**。旧文件、未完成传输和正在录制的文件继续留在原位置。选择目录不会自动共享它。

## 查找与保存文件 {#library}

在**文件缓存**按名称搜索，或按可用状态、文件类型筛选。打开完整文件预览，或使用**文件操作**：

- **保存到设备**：导出浏览器存储中的文件。
- **另存为**：把目录文件复制到其他位置。
- **打开位置**：定位 Windows 文件；**查看详情**可检查附件引用。

目录中的已有文件会直接显示，无需复制到另一份缓存。未完成传输可能带有 `.part` 后缀，等任务完成后再使用。更多操作见[保存副本](files.md#save-and-preview)。

## 删除文件与释放空间 {#cleanup}

1. 先为需要保留的内容保存并检查副本。
2. 在**文件缓存**选中不再需要的文件，点击**删除本地文件**。
3. 确认前阅读受影响的附件提示，需要时先用**查看详情**检查引用。

**删除目录文件会删除实际文件**。聊天消息可能仍在，但附件不可用。**取消共享**只改变访问权限，不会释放空间。

::: details 切换目录、查找旧文件或恢复目录访问

### 切换存储位置 {#change-directory}

#### 选择其他位置 {#switch-location}

回到**设置 → 传输 → 文件存储**，选择其他目录或浏览器存储。

在**文件缓存**查看旧文件时，重新选中原存储位置。这也会改变新文件的目标，查看后可改回常用默认位置。桌面端也可通过**打开目录**，在系统文件管理器中查看已挂载目录，不修改默认位置。

#### 浏览器目录重新授权 {#restore-access}

存储设置中出现**重新连接目录**时，点击并允许访问。保持移动磁盘连接，再尝试打开已知文件。恢复授权不需要清除站点数据。
:::

::: details 浏览器存储、清除数据与升级迁移

浏览器文件受当前站点存储配额限制。清除站点数据可能删除这些文件、聊天、身份和设置，操作前先导出需要的文件。

清除应用设置不会自动删除真实目录文件，但访问与共享设置可能需要恢复。

### 升级后的迁移 {#migration}

旧浏览器存储可能自动迁移。保持页面打开，等复制与校验完成后检查文件；关闭文件面板不会停止迁移。这与选择新默认目录不同，后者不会移动已有文件。
:::

- **想录下屏幕并找到文件**：按[录制与保存](recording.md)操作。
- **文件找不到或保存失败**：查看[文件与存储常见问题](faq.md#files)。
