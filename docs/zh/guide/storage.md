# 文件存储与管理

文件存储设置决定新接收文件和录制保存在哪里。它与聊天历史、设备身份和权限记录是不同的数据；选择真实目录不会把这些设置一起搬到目录中。

## 选择存储位置 {#choose-storage}

打开**设置 → 传输 → 文件存储**，先选择存储方式，再按需要选择目录。

| 方式                    | 适用客户端                       | 使用特点                                           |
| ----------------------- | -------------------------------- | -------------------------------------------------- |
| 浏览器存储（IndexedDB） | 浏览器和桌面端                   | 无需选择目录；文件属于当前应用配置，受存储配额影响 |
| 本地目录                | 桌面端，以及支持目录选择的浏览器 | 文件直接存入所选目录，可与系统文件管理器一起使用   |

浏览器默认使用 IndexedDB。桌面端默认使用应用本地数据下的文件目录，也可选择其他位置。

浏览器目录选择需要 HTTPS 等安全上下文以及用户授权。

## 切换目录与重新授权 {#change-directory}

1. 在本地目录模式下，通过目录选择器选择新目录。
2. 确认当前显示的位置，再接收新文件或开始录制。
3. 查看旧文件时，切回原来的存储位置。

切换只影响新文件，已有文件和活跃任务继续使用原来的位置。批量“另存为”只保存副本，不会更改默认目录。

浏览器重新打开页面后可能需要重新授权。目录不可用时，使用界面中的重新连接操作并完成授权；也检查移动磁盘是否连接。恢复权限不需要清除站点数据。

## 使用文件库 {#library}

所选目录中的现有文件也会出现在文件库中，无需先复制到另一份缓存。目录里的隐藏文件和浏览器临时文件不会作为普通文件展示。

- 文件菜单提供预览、打开、另存为或保存到设备等操作，具体取决于文件所在位置。
- Windows 目录文件可使用“打开文件位置”，直接在系统文件管理器中定位。
- 同名接收文件会保留既有文件，并使用编号名称。
- 未完成的目录传输通常带有 `.part` 后缀；完成前不要把它当成可用的完整文件。

共享需要主动开启，并受对方设备的文件列表权限控制。挂载目录不会自动分享其中全部内容，详见[文件共享](files.md#shared-files)。

## 删除与释放空间 {#cleanup}

在文件管理器中删除目录文件，会删除对应的实际文件。删除聊天附件引用与删除实际文件是不同操作；操作前确认文件位置及是否还需要保留副本。

清理浏览器站点数据会影响浏览器存储中的文件、聊天和设备配置。需要保留的文件应先保存到设备。真实目录中的文件字节不会因清除应用设置而自动删除，但目录授权、聊天引用和共享设置可能需要重新建立。

## 升级时的存储迁移 {#migration}

升级后，旧浏览器文件存储可能自动迁移。应用会显示文件数量及复制、校验进度，关闭文件面板不会停止这项操作。

## 接下来想了解什么？ {#troubleshooting}

- **想让其他设备浏览你选定的文件**：继续了解[共享文件列表](files.md#shared-files)。
- **想把屏幕或视频来源录制成文件**：按[录制步骤](media.md#recording)开始操作。
- **想理解未完成文件恢复和数据删除边界**：深入了解[存储生命周期](../architecture/storage.md)。
- **文件无法读取，或接收、录制保存失败**：前往[文件访问与保存常见问题](faq.md#files)。
