# 文件存储与管理

先选择新接收文件和录像写入哪里，再通过**用户菜单 → 文件缓存**管理。虽然界面名称是**文件缓存**，本地目录模式下的内容仍是该目录中的真实文件。

聊天历史、设备身份与权限是另一类数据，选择文件目录不会把这些记录一起移入目录。

## 选择保存位置 {#choose-storage}

| 你的需要                 | 保存方式                    | 实际含义                                                       |
| ------------------------ | --------------------------- | -------------------------------------------------------------- |
| 不选文件夹，直接开始使用 | **浏览器存储**（IndexedDB） | 文件属于当前站点与配置，受对应存储配额限制                     |
| 直接写入自己管理的文件夹 | **本地目录**                | 桌面端及支持目录访问的浏览器可用，文件可在系统文件管理器中看到 |

浏览器默认使用浏览器存储；桌面端默认使用应用本地数据下的目录，也可以另选位置。浏览器目录访问需要 HTTPS 等安全上下文，以及你的授权。

1. 点击头像，打开**用户菜单 → 设置 → 传输 → 文件存储**。
2. 在**保存方式**中选择**浏览器存储**或**本地目录**。
3. 使用本地目录时，点击**选择目录**，选定目标文件夹，并按提示允许访问。
4. 开始新的传输或录像前，核对当前方式和显示的目录。
5. 接收一个小文件，等待完成，再打开**用户菜单 → 文件缓存**查找。桌面端也可用**打开目录**在系统文件管理器中查看。

**成功的标志**：一个新的完整文件出现在选定位置。选择目录本身不会把已有文件复制过去，也不会向其他设备共享目录内容。

## 切换位置与恢复访问 {#change-directory}

### 将后续文件写到其他位置 {#switch-location}

1. 回到**设置 → 传输 → 文件存储**。
2. 通过**本地目录 → 选择目录**换一个文件夹，或改为**浏览器存储**。
3. 核对显示的目标位置，再新建一次传输或录像验证。

修改只作用于**新文件**。已有文件、未完成传输和已经开始的录像继续使用原位置；批量**另存为**也只是创建副本，不改变默认位置。

需要在**文件缓存**中浏览旧文件时，重新选择其原来的存储位置。这也会改变后续新文件的位置，查看后可按需改回常用默认位置。桌面端也可通过文件库中的**打开目录**菜单，在系统文件管理器打开已挂载的目录，不必修改默认位置。

### 为浏览器目录重新授权 {#restore-access}

1. 打开文件存储设置，确认选中的是需要访问的目录。
2. 出现**重新连接目录**时，点击并在浏览器提示中允许访问。
3. 保持移动磁盘等设备连接，再打开**文件缓存**，尝试打开一个已知文件。

浏览器重新打开页面后可能需要再次授权。恢复已有目录的权限不需要清除站点数据；仍无法访问或写入时，按[存储检查](faq.md#storage-full)排查。

## 查找与管理文件 {#library}

1. 打开**用户菜单 → 文件缓存**。
2. 按名称搜索，使用**可用状态**、**文件类型**或**排序**缩小范围。
3. 选中可用的完整文件，打开**文件操作**；**查看详情**可以检查文件名称和关联附件。
4. 按需要选择操作：

| 你的目的                  | 操作                                 |
| ------------------------- | ------------------------------------ |
| 查看内容                  | 预览，或使用支持的应用打开           |
| 在浏览器存储之外保留副本  | **保存到设备**                       |
| 将目录文件复制到其他位置  | **另存为**                           |
| 在 Windows 中定位目录文件 | **打开位置**                         |
| 向其他设备提供选定文件    | **共享**，并允许接收设备浏览文件列表 |

所选目录中的现有文件会直接显示，无需先复制到另一份缓存。隐藏文件和浏览器临时文件不会作为普通文件展示；新接收文件遇到同名内容时，会保留既有文件并使用编号名称。

未完成的目录传输通常带有 `.part` 后缀，应等任务完成后再作为完整文件使用。导出与批量复制的完整步骤见[保存副本](files.md#save-and-preview)，提供文件的步骤见[共享文件列表](files.md#shared-files)。

## 删除文件与释放空间 {#cleanup}

1. 在**文件缓存**中找到不再需要的文件。
2. 需要保留的内容，先使用**保存到设备**或**另存为**创建并检查副本。
3. 需要确认哪些附件仍在引用文件时，先打开**查看详情**。
4. 点击**删除本地文件**，阅读受影响的附件引用提示，确认只删除自己选定的内容。

删除本地目录文件会移除实际文件，在系统文件管理器中删除也一样。聊天消息可能仍在，但附件内容已不可用；清空聊天和删除底层文件是不同操作。

取消共享只改变访问权限，不会释放存储空间。清除浏览器全部站点数据还可能移除浏览器存储中的文件、历史、身份和设置，操作前先导出需要的内容。

清除应用设置不会自动删除真实目录中的文件字节，但目录授权、聊天引用和共享设置可能需要重新建立。

## 等待升级后的存储迁移完成 {#migration}

升级后，旧浏览器文件存储可能自动迁移。

1. 文件数量及复制、校验进度推进时，保持应用或页面打开。
2. 等迁移结束后，再考虑清理旧浏览器数据。
3. 打开**文件缓存**，检查需要保留的几个文件。

关闭文件面板不会停止迁移。这种升级迁移与选择新默认目录不同，后者不会移动已有文件。

## 接下来想了解什么？ {#troubleshooting}

- **想让另一台设备浏览选定文件**：按[共享文件列表](files.md#shared-files)操作。
- **想录下屏幕并找到生成的文件**：使用[录制与保存](recording.md)。
- **文件找不到，或保存失败**：查看[文件与存储常见问题](faq.md#files)。
- **想理解未完成文件与数据删除的边界**：阅读[存储生命周期](../architecture/storage.md)。
