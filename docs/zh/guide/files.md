# 文件传输与共享

Weblink 可以从聊天发送文件，也可以让对方浏览你主动共享的文件列表。文件通过设备之间的 WebRTC 连接传输；发送方需保持在线。

## 发送与接收 {#send-and-receive}

1. 加入房间，在房间聊天或成员私聊中选择文件，也可以拖入文件。
2. 检查发送确认内容。选择文件夹时，按提示将其打包为 ZIP。
3. 发送后查看传输任务；接收方从附件卡片下载并查看进度。
4. 完成后在文件库或附件菜单中预览、打开或保存文件。

房间附件默认由接收方主动下载。若希望自动接收小文件，接收方可在该房间的设置中开启自动下载，并在**设置 → 传输**中调整大小限制。

消息已送达表示对方收到消息或附件信息，文件是否下载完成要看传输进度。后来加入房间的成员不会自动收到以前的附件。

## 暂停、继续与重试 {#tasks}

在任务列表中，根据当前状态使用暂停、继续、重试或取消。房间文件的菜单提供详情，可分别查看各接收者的进度。

断线后，保持原文件和存储目录可用，重新连接，再继续或重试任务。可恢复的已接收部分会被复用。

关闭文件面板不会取消已经开始的传输。要停止任务，请使用任务本身的控制；退出房间会中断当前设备连接。

## 使用共享文件列表 {#shared-files}

1. 在本地文件库中选中完整文件，开启共享。
2. 在对方设备的权限设置中允许“提供文件列表”。
3. 对方打开你的成员文件面板，搜索、排序、预览或批量下载内容。

导入或接收文件不会自动共享。新发送的文件会自动共享，之后可在文件库关闭；选择一个存储目录也不会把其中所有文件自动开放给别人。

从共享列表下载的内容进入文件库和任务列表，不会额外生成聊天消息。关闭共享后，对方已经保存的副本不会被远程删除。

## 文件保存在哪里 {#storage}

浏览器默认保存在当前站点的浏览器存储中，桌面端默认使用本地文件目录。要改变新文件的位置，在**设置 → 传输 → 文件存储**中选择存储方式和目录。

切换默认位置不会移动旧文件、进行中的传输或录制。具体配置、目录授权与清理方式见[文件存储与管理](storage.md)。

## 预览与保存副本 {#save-and-preview}

完整文件可以从附件或文件库中预览。桌面端可以使用系统默认应用打开文件；目录文件还可在文件菜单中打开文件位置。

- 浏览器存储中的文件使用“保存到设备”。
- 目录文件使用“另存为”，原文件保留在原位置。
- 批量保存只需选择一次目标目录；同名冲突时可以覆盖、跳过或保留两份。
- 取消批量保存会停止后续文件，已完成的副本保留。关闭文件管理器不会自动取消后台保存。

## 接下来想了解什么？ {#troubleshooting}

- **想把收到的文件保存到指定目录**：继续设置[文件存储位置](storage.md#choose-storage)。
- **想测量两台设备之间的传输能力**：尝试[连接测速](connection.md#speed-test)。
- **想理解分块、续传和完整性校验**：阅读[文件传输协议](../architecture/file-transfer.md)。
- **附件无法下载、文件不可用或保存很慢**：在[文件与存储常见问题](faq.md#files)中查找处理方式。
