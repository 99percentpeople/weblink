# 文件传输与共享

在聊天中发送文件，或提供共享列表让对方自行选择。

### 传输前 {#before-you-start}

先[连接设备](rooms.md#join)。保持发送端在线、原文件可用，并确认接收端的[保存位置](storage.md#choose-storage)。

## 发送与接收文件 {#send-and-receive}

### 发送端 {#send}

打开房间群聊或成员私聊，选择**发送文件**或拖入文件，核对目标会话后发送。

### 接收端 {#receive}

点击附件上的传输操作，房间附件对应**点击传输**。等待**保存 / 合并中**结束，再打开完整文件；也可在**用户菜单 → 任务列表**查看进度。

**附件卡片只是文件信息，不代表已经下载完成**。房间中各接收者分别下载；**本地已有，已跳过传输**表示复用了可用的本地内容。

::: details 文件夹、文件库已有文件与自动接收

使用**发送文件夹**将文件夹打包为 ZIP，或用**从文件列表选择**发送文件库中的已有内容。

### 自动接收房间中的小文件 {#automatic-downloads}

在接收端打开**房间信息与设置 → 房间设定**，将**允许自动下载文件**设为**允许**，再到**设置 → 传输 → 自动下载文件大小上限**选择大小。

它只作用于该房间的新文件，不补下载历史；上限由所有已启用的房间共用，超出上限仍可手动下载。

传输设置中单独的**自动下载**是在接收完成后保存文件，不代替房间自动接收权限。
:::

::: details 暂停、继续与查看各接收者进度

### 传输任务 {#tasks}

打开**用户菜单 → 任务列表**，使用当前状态提供的暂停、继续、重试或取消操作。房间文件的**查看详情**可以检查每个接收者。

断线后回到原房间，保持发送者在线、两端存储可访问，再继续任务；可恢复的数据会被复用。关闭任务或文件面板不会停止传输，离开房间会中断连接。
:::

## 共享可浏览的文件列表 {#shared-files}

### 提供文件的一端 {#share}

打开**用户菜单 → 文件缓存**，选中完整文件并点击**共享**；在**设置 → 客户端与房间**中，为接收设备允许**提供文件列表**。

### 接收文件的一端 {#browse-shared}

在**成员**中点击提供者旁的**共享文件**，选中文件后点击**获取**或**获取选中项**。到**任务列表**查看进度，完成后在**文件缓存**打开。

共享列表**跨房间共用**，按设备控制访问。新发送的文件会自动共享，导入或接收不会自动共享。**取消共享**不会删除别人已经保存的副本。

## 保存副本 {#save-and-preview}

从完成的附件或**用户菜单 → 文件缓存**打开文件操作：

- **保存到设备**：导出浏览器存储中的文件。
- **另存为**：将目录文件复制到其他位置。
- Windows 中的**打开位置**：定位实际文件。

### 默认保存位置 {#storage}

在**设置 → 传输 → 文件存储**修改。新位置只影响新文件，旧文件和活跃任务仍留在原位置，详见[文件存储](storage.md)。

::: details 一次保存多个文件

选中文件后使用可用的保存操作。批量**另存为**只选择一次目标目录，同名时可覆盖、跳过或保留两份。取消会停止后续文件，保留已完成副本；关闭文件管理器不会取消后台保存。
:::

## 接下来想了解什么？ {#troubleshooting}

- **想选择目录或释放空间**：按[文件存储与管理](storage.md)操作。
- **想测量这两台设备的连接**：运行[对端测速](connection.md#speed-test)。
- **文件不可用或保存失败**：查看[文件与存储常见问题](faq.md#files)。
