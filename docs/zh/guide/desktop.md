# 安装与使用桌面端

桌面端适合需要原生屏幕共享、接收远程控制、系统文件操作或 MCP 自动化的 Windows 电脑。浏览器和桌面端可以进入同一个房间。

需要为自己的服务预设信令和网页邀请地址，或从源码构建安装包时，见 [Tauri 端部署](../deployment/tauri.md)。

## 下载与安装 {#install}

目前支持 Windows 10 22H2 / Windows 11 x64，需要 WebView2 120 或更新版本。

1. 打开 [Weblink 下载页面](https://github.com/99percentpeople/weblink/releases/latest)。
2. 选择 Windows 安装包，或下载免安装 ZIP。
3. 安装版按向导完成安装；需要时，安装程序会安装或更新 WebView2。
4. 免安装版先解压，再运行其中的可执行文件。保留旁边的 `weblink-portable` 标记，并确保电脑已安装 WebView2。

## 第一次连接 {#first-connection}

打开应用，填写显示名称和房间 ID；另一台设备使用相同信令服务、房间 ID 和密码加入。详细步骤见[房间与聊天](rooms.md)。

使用自建服务时，在**设置 → 连接**填写自己的信令地址。桌面安装版连接非本机地址时应使用 `wss://`；仅在本机测试可使用 `ws://127.0.0.1:9000`。

首次连接会进行[设备配对](device-trust.md)。远程控制和自动化需要另行授权，安装应用或进入房间不会自动开放这些权限。

## 文件、窗口与通知 {#daily-use}

- 接收的文件默认保存在应用本地数据下的文件目录；可在**设置 → 传输 → 文件存储**选择其他目录。
- 文件菜单可以使用系统默认应用打开文件、另存为，或打开文件位置。详见[文件存储与管理](storage.md)。
- 隐藏或最小化主窗口不会自动退出房间或停止已有共享。需要完全退出时，从托盘选择退出。
- 在设置中的通知选项选择需要提醒的类别、声音和内容预览；还需允许 Windows 显示 Weblink 通知。
- 点击系统通知可以回到相关会话或待审批请求。打开通知本身不会批准远程访问。

系统通知依赖应用仍在运行，不能代替离线消息接收。

## 检查与安装更新 {#updates}

在**设置 → 关于**查看版本并手动检查更新，也可以开启自动检查。自动检查只提示可用版本，不会自动下载或安装。

安装版按界面提示确认更新；安装会结束当前会话并重启应用，请先完成需要保留的传输和录制。免安装版使用页面提供的 ZIP 下载入口，退出应用后解压替换，保留免安装标记。

## 接下来想了解什么？ {#troubleshooting}

- **想从手机或另一台设备控制这台电脑**：继续设置[远程桌面](remote-control.md)。
- **想让 AI 客户端执行已授权操作**：继续配置 [MCP 与自动化](automation.md)。
- **想将自建服务地址预置到安装包中**：阅读 [Tauri 端配置](../deployment/tauri.md#configuration)。
- **遇到白屏或无法启动**：检查[桌面端运行环境](faq.md#desktop-start)。
